# Temperature Conversion and Analysis System

A simple C programming project that converts city temperatures between Celsius, Fahrenheit, and Kelvin using pointers and file handling.

## Features
- Temperature conversion
- Hottest and coldest city detection
- Average temperature calculation
- Save converted temperatures to a text file
- Read saved temperatures

## Technologies Used
- C Programming Language
- VS Code
- GCC Compiler

## How to Run on Windows

Compile:
gcc temperature_system.c -o temperature_system.exe

Run:
.\temperature_system.exe

## Concepts Used
Functions, pointers, arrays, loops, conditional statements, and file handling.
